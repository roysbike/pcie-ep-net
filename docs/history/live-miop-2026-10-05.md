## Cluster Box after `echo 1 > /sys/bus/pci/rescan`

RC scanned empty at boot (EP not ready). Rescan found:

```
02:04.0-[04]----00.0  Mixtile Limited Blade 3 [4586:b6f2]
```

`04:00.0` class `0280` Network controller, `Kernel driver in use: miop`.

| Item | Value |
| --- | --- |
| Downstream `LnkSta` | **8 GT/s, width x2** (cap x4; downgraded) |
| Equalization | complete, phases 1–3 |
| BAR0 | 64-bit prefetchable **32 MiB** `@ 0x22000000` |
| BAR4 | 64-bit prefetchable **1 MiB** `@ 0x21000000` |
| ROM | 64 KiB `@ 0x20100000` |
| Resizable BAR | BAR0=32M, BAR1–5 advertised 1M |
| MSI | 1/32, 64-bit, maskable, **disabled** |
| MSI-X | 128 vectors, table BAR4+0x20000, PBA BAR4+0x28000, **disabled** |
| ATS / PRI | present on vendor EP (upstream RK3588 EPC hides ATS) |
| Bridge windows | mem 1 MiB `0x20100000` + pref 48 MiB `0x21000000–0x23ffffff` |

dmesg (RC):

```
miop 0000:04:00.0: PCIe bus number 4 mapped to MIOP node id: 3
miop 0000:04:00.0: pci_alloc_irq_vectors() only alloc 1 vectors
miop 0000:04:00.0: MIOP node[3] on bus:04 is online
```

dmesg (EP, after host bind):

```
miop-ep fe150000.pcie: Descriptor PCI address: 22000000
miop-ep fe150000.pcie: MSI not enabled, check on legacy interrupt.
miop-ep fe150000.pcie: irq line: 4
miop-ep fe150000.pcie: Node online: 80000003
miop-ep fe150000.pcie: TX[3]: Queue is ready.
```

So the 32 MiB BAR0 is the **descriptor / shared-memory window**,
PCI address published to the EP as `0x22000000`. Doorbell is
**legacy INTx (IRQ 4)** because MSI allocation failed on MT7620A
(`only alloc 1 vectors` then still “MSI not enabled”).

## Implications for openmiop

1. Vendor EP is a **platform driver** on `fe150000.pcie`, not
   Linux PCI Endpoint Framework. U-Boot compatible rewrite is
   confirmed on this Debian image.
2. Standard Type-0 function **does** appear (`4586:b6f2`) once the
   RC rescans after LTSSM up. Phase 1 with `pci_epf_test` /
   `1d87:3588` should enumerate the same way.
3. Practical BAR budget on this RC: **32 MiB + 1 MiB** already
   assigned; bridge grabbed 48 MiB prefetch + 1 MiB non-pref.
   Four blades × 32 MiB = 128 MiB, still inside the 256 MiB
   MT7620A window.
4. MSI to the MT7620A is weak; vendor falls back to **INTx**.
   Our stack should treat MSI as optional.
5. Jumbo MTU (~64 KiB) is intentional (one descriptor ≈ one skb).
6. Link trained **Gen3 x2**, not x4. First performance ceiling is
   ~16 Gbit/s raw before protocol overhead. Vendor “19 Gbit/s”
   claim is therefore either x4 on other firmware or slightly
   optimistic vs this slot.
7. `pci_epf_test` remains the right Phase 1 path. Do not bind
   `4586:b6f2` until we want to coexist with `miop.ko`.
