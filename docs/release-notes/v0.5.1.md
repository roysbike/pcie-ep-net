## Summary

openmiop **v0.5.1** is a build fix for the Cluster Box module `omi-rc`:
it now compiles with Linux 6.1 and later, where `netif_napi_add()` lost
its weight argument. This is needed for ClusterBox firmware on OpenWrt
25.12 (Linux 6.12), which is in development.

* Nothing changes at run time. The blade driver (`openmiop-ep`) is the
  same code as in v0.5.0, and on the current firmware (OpenWrt 23.05,
  Linux 5.15) `omi-rc` builds exactly as before.
* No update is needed for running systems: blades on mixtile-talos
  v0.5.0 and BMCs on ClusterBox firmware v0.3.0 already run the
  equivalent code.
* The 6.12 build was checked in the firmware CI (the module is
  in the image with vermagic 6.12.94). It has not run on hardware yet: the
  first OpenWrt 25.12 firmware build did not boot on the BMC and was
  withdrawn.

Changes: [CHANGELOG.md](https://github.com/roysbike/pcie-ep-net/blob/v0.5.1/CHANGELOG.md).
