## Summary

openmiop **v0.5.2** fixes the Cluster Box module `omi-rc` on ClusterBox
firmware built on OpenWrt 25.12 (Linux 6.12): with it the blades connect
to the BMC again.

* On Linux 6.12 the PCIe switch ports above the blades (ASM2824) stay
  disabled: no driver binds them, and their COMMAND register is 0000.
  Without bus mastering the switch rejects the blades' writes towards the
  BMC, so a blade's state never arrived, the blades logged `RC push mode:
  state at ...` every second and omi0 had no peers.
* `omi-rc` now enables memory and bus mastering on every bridge from the
  blade up to the root port when it attaches a blade, and logs it:
  `omi0: node N 0000:02:xx.0: bridge 0000:01:00.0: memory and bus mastering enabled`.
* Checked on the Cluster Box with 4 blades: after a BMC reboot all four are
  `active ... gateway pull, zero-copy` about 150 s after boot without any
  manual step.
* The blade driver (`openmiop-ep`) is the same code as in v0.5.0; no blade
  update is needed. On the current firmware (OpenWrt 23.05, Linux 5.15) the
  bridges are already enabled and nothing changes.

Changes: [CHANGELOG.md](https://github.com/roysbike/pcie-ep-net/blob/v0.5.2/CHANGELOG.md).
