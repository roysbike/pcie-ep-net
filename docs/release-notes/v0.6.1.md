## Summary

openmiop **v0.6.1** carries the Blade 3 board modules, so one source
release has everything the Talos extension builds. The drivers
themselves are the same as in v0.6.0.

* **`drivers/blade3`:** `blade3-leds` (activity LEDs of the RTL8125
  2.5GbE ports, also at 2.5 Gbit/s) and `blade3-nvme-recover` (brings the
  M.2 NVMe back after the Cluster Box pulsed PERST#, e.g. on a BMC
  reboot). Both moved unchanged from mixtile-talos, where they were built
  next to the extension until now. Build with
  `make -C drivers/blade3 KDIR=<kernel build tree>`;
  `blade3-nvme-recover` needs a full build tree (private DesignWare
  header), so neither is in the DKMS package.
* CI compiles `openmiop-ep` and both board modules against Linux 6.18,
  the kernel series of Talos v1.14.
* `openmiop-ep`, `omi-rc`, the BMC helper and protocol v4 are unchanged:
  nothing to update on the blades or the BMC because of this release.

Changes: [CHANGELOG.md](https://github.com/roysbike/pcie-ep-net/blob/v0.6.1/CHANGELOG.md).
