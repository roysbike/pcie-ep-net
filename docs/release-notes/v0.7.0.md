## Summary

openmiop **v0.7.0** makes the blade's TX path faster and keeps less data
queued in the driver, so latency under load drops. Only the sender
changes: wire format, BAR layout and handshake stay protocol v4.

* **Byte queue limits (BQL)** on every TX queue. v0.6 kept up to 256
  frames per queue (~2.3 MB at MTU 9000) below the qdisc, where fq could
  not reorder them. BQL now caps that backlog to about two eDMA runs.
* **Chained eDMA runs.** Each TX thread builds the next run while the
  current one is on the wire and starts it at the done interrupt, before
  it retires the finished run. Before, the engine idled for the retire
  and the next list build (~13 us per run). Parameter `tx_chain`
  (default on, writable at runtime), ethtool counter `tx_dma_chained`.
* **Shorter runs: at most 16 frames** (was 32), parameter `tx_batch`
  (1-32, writable at runtime). With chaining the shorter runs cost no
  throughput and halve the BQL limit to ~288 KB per queue.
* Fix: a run retired after a peer reconnected could overwrite that
  peer's reset ring head (see CHANGELOG).
* `omi-rc` and the BMC helper are unchanged; the BMC needs no update.

Changes: [CHANGELOG.md](https://github.com/roysbike/pcie-ep-net/blob/v0.7.0/CHANGELOG.md).

## Measured

Lab Cluster Box, Talos v1.14.4, MTU 9000, fq on `omi0`, a v0.7 blade
sending to a v0.6.1 blade, under cluster load:

| | v0.6.1 | v0.7.0 |
| --- | --- | --- |
| 1 TCP flow | 7.65-8.0 Gbit/s | 8.47-8.57 Gbit/s |
| 4 TCP flows | 10.6-11.3 Gbit/s | 11.6-11.9 Gbit/s |
| 8 TCP flows | 10.6-10.8 Gbit/s | 11.5-11.9 Gbit/s |
| Ping under 8-flow load, avg / max | 1.6-1.9 / 6.6-7.6 ms | 1.4-1.5 / 3.8-4.6 ms |

Also checked: SHA-256 of 4 parallel 512 MB transfers, 3 times each way
(24/24 match); UDP 4 x 9 KB flows without driver drops; a 1 h
bidirectional run (3.28 TB out, 3.14 TB in, ~8 Gbit/s each way) with no
error counter and no peer down; three reboot/reset cycles of the v0.7
blade under load, reconnected each time.

## Verification

On a blade:

```sh
cat /sys/module/openmiop_ep/parameters/tx_chain /sys/module/openmiop_ep/parameters/tx_batch   # Y, 16
cat /sys/class/net/omi0/queues/tx-0/byte_queue_limits/limit   # grows under load, ~288 KB
ethtool -S omi0 | grep -E 'tx_dma_chained|tx_dma_errors'      # chained grows, errors 0
```
